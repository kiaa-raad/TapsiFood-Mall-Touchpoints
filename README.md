# پروپوزال حضور تپسی و تپسی‌فود در مال

فایل index.html را در مرورگر باز کنید. فایل‌های CSS و JavaScript و پوشه assets کنار آن باقی بمانند.

صفحه شامل بنچمارک‌های منتخب، پیشنهاد خدمات و مسیریابی و چهار تصویر پیشنهادی برای ایستگاه مسافر تپسی است:
- ایستگاه انتظار با نیمکت، سایه‌بان، شارژ و نمایشگر
- تابلوی آویز در راهروی مال
- پوشش ستون پارکینگ با کد T1
- توتم معرفی ورودی و خدمات ایستگاه

این تصاویر تجسم طراحی هستند، نه عکس اجرای واقعی. طراحی کانتر تعامل و هاب تحویل غذا هنوز نهایی نشده و در صفحه با وضعیت «در حال توسعه» مشخص شده است. ابعاد نمایشی و کد محل باید با سایت واقعی تطبیق داده شوند.

برای انتشار در GitHub Pages، index.html، فایل‌های CSS و JavaScript، پوشه assets و فایل .nojekyll را با همین ساختار در ریشه مخزن قرار دهید. پروژه استاتیک است و مرحله build ندارد.

عکس‌های بنچمارک دارای منبع‌اند و حقوق آن‌ها متعلق به صاحبان اثر است.
