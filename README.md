# پروپوزال حضور تپسی و تپسی‌فود در مال

فایل index.html را در مرورگر باز کنید. فایل‌های CSS و JavaScript و پوشه assets کنار آن باقی بمانند.

محتوا: ۸ کیس‌استادی منتخب با ۱۱ عکس مرجع، پیشنهاد ایستگاه مسافر و خانواده سایناژ، امکانات خدماتی، سه سطح هاب غذای دارای مسئول ثابت و شلف، و کانتر «ایستگاه انتخاب». سایر نمونه‌های بنچمارک از صفحه حذف شده‌اند. تصاویر استفاده‌نشده حذف شده‌اند و پوشه assets فقط شامل تصاویر موردنیاز صفحه، فونت و مجوز آن است.

فایل gemini-design-prompts-fa.md شامل یک پرامپت مادر و ۹ پرامپت شات است. همین متن‌ها در انتهای صفحه با دکمه کپی قرار دارند. در محیطی که کپی خودکار مجاز نباشد، متن برای کپی دستی انتخاب می‌شود.

رندرهای قبلی فقط برای تشخیص مسئله استفاده شده‌اند؛ تصاویر آن‌ها در این صفحه قرار نگرفته‌اند و ابعاد یا لوگوهای تولیدشده‌شان مبنای طراحی نیست.

صفحه مفهومی است؛ ابعاد، ظرفیت، تجهیزات، قیمت و جانمایی نهایی باید با محل واقعی بررسی شوند. گایدلاین رسمی و لوگوی اصلی مرجع نهایی تولید تصویر هستند.

## انتشار در GitHub Pages

تمام فایل‌های پروژه، از جمله index.html، فایل‌های CSS و JavaScript، پوشه assets و فایل gemini-design-prompts-fa.md را با همین ساختار در ریشه مخزن آپلود کنید. فایل .nojekyll نیز همراه پروژه باشد.

در تنظیمات مخزن، بخش Pages، انتشار از شاخه (Deploy from a branch) را انتخاب کنید و شاخه حاوی فایل‌ها و پوشه / (root) را به‌عنوان منبع قرار دهید. این پروژه استاتیک است و به نصب وابستگی یا مرحله build نیاز ندارد.
