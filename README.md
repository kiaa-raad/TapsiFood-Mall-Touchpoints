# تپسی در ایران مال | گالری ریسرچ و طرح‌ها

فایل index.html را باز کنید. صفحه با ریسرچ باز می‌شود و دو مسیر مستقیم دارد: «طرح پیشنهادی» (۵ تصویر) و «ریسرچ» (۸ نمونه با فیلتر موضوع). زیر تصاویر فقط توضیح کوتاه قرار دارد؛ منابع ریسرچ کنار هر نمونه‌اند.

- طرح‌ها: ایستگاه مسافر، کیوسک تحویل غذا، کانتر تعامل، تابلوی مسیر و ستون پارکینگ.
- تصاویر پیشنهادی با نام انگلیسی و فرمت WebP در assets هستند.
- کلیک روی عکس: نمایش بزرگ، پیمایش قبلی/بعدی و کلیدهای جهت. Escape تصویر را می‌بندد.
- نشانی مستقیم: #designs برای طرح‌ها و #research برای ریسرچ.
- برای انتشار، index.html، CSS، JavaScript، پوشه assets و .nojekyll را با همین ساختار نگه دارید.

تصاویر پروژه تجسم طراحی‌اند و ابعاد و محتوای کمپین در مرحله اجرا نهایی می‌شوند. تصاویر ریسرچ متعلق به صاحبان اثرند. فونت وزیرمتن محلی با مجوز SIL OFL بارگذاری می‌شود.
